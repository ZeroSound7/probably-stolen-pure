# 可能是纯的 / Probably Pure

《深空当铺 / Probably Stolen》(0.46D) 的 Mod：新增 **一台 2×3 纯溶液净化机**，配合 **5 张可重复使用的工艺芯片**（酸 / 碱 / 脂合剂 / N-羟基甲碱 / 还原剂），把化学用品拆包得到的含杂质试剂提纯成纯溶液。

- Mod ID：`pure_acid_alkali`（保持稳定，后续只调概率不改 ID）
- 版本：1.3.2
- 前置：无

## 安装与启用

1. 把 `PureAcidAlkali` 文件夹放进游戏目录的 `Mods\`。
2. 启动游戏 → 主菜单「模组」→ 启用「可能是纯的」→「审核并启用」→ **重启游戏**。
3. **重启之后**再载入存档。如果 Mod 还没实际加载就载入了含本 Mod 物品的存档，游戏会把未知物品换成占位物，这次读档可能异常、物品栏显示为空（原版行为，不是存档损坏）；不要保存，退出重进、确认 Mod 已启用后再读档即可。首次启用前建议备份存档。
3. 在**杰克逊博士（发明家）**的货单里购买：
   - 纯溶液净化机：基础价值 **300**
   - 工艺芯片：酸 / 碱 / 脂合剂 / N-羟基甲碱 / 还原剂，每张基础价值 **100**
   - 机器补货概率 **25%**（和净水器同档）；**没拥有过的芯片仍然必出**，直到买到为止。

## 使用

1. 机器放进机器区（占 **2×3** 格）。
2. 打开机器，从左到右：**电源 / 模组 / 溶液容器 / 工艺芯片 / 右侧小纸条**。
3. 放入：
   - **电源**：有电的能量电池（基础耗电 8/次，效率芯片降低）
   - **模组**：通用芯片（性能 / 效率 / 质量）
   - **溶液容器**：装含杂质试剂的、归你所有的液体容器
   - **工艺芯片**：决定保留哪种液体
4. 关店过夜，机器把「保留集合」之外的液体按额度去除并等量转成目标液体。
5. 没有实际去除杂质时不扣电；输入已经比当前质量上限更纯时不会降纯。

## 五种芯片

| 芯片 | 保留的液体 | 说明 |
|---|---|---|
| 工艺芯片·酸 | `acid` | 去掉其他成分 |
| 工艺芯片·碱 | `base` | 去掉其他成分 |
| 工艺芯片·脂合剂 | `lipobond_agent` | 去掉其他成分 |
| 工艺芯片·N-羟基甲碱 | `methylol` + `stabilizing_agent` | **稳定剂是正常流程的一部分，保留不动**，只去除四类杂质 |
| 工艺芯片·还原剂 | `reducing_agent` | 去掉其他成分 |

纯度按「保留集合总量 / 液体总量」计算，所以 N-羟基甲碱的稳定剂不会被当成杂质扣掉。

## 数值（集中在 `src/PurifierMath.cs`）

| 属性 | 作用 |
|---|---|
| 质量 Q | 纯度上限：Q=0 → 98%，Q=25 → 99%，Q=50 → 100%（中间线性，≥50 恒 100%） |
| 性能 P | 每晚去除量：P=0 → 10 mL，P=50 → 20 mL（线性：10 + 0.2×P mL） |
| 效率 E | 降低每次耗电（基础 8；+16% 效率芯片 8→7） |

- 以上是参考值；实际数值在游戏内看物品提示框和右侧说明书。
- 机器价值 300、芯片价值 100、基础耗电 8。
